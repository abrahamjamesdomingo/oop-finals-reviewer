# OOP Finals Reviewer

My personal reviewer for **CS 212 — Object Oriented Programming (VB.NET)** finals.

**Open it here:** <https://abrahamjamesdomingo.github.io/oop-finals-reviewer/>

## What's inside

- **Lessons** — Classes & Objects, Encapsulation, Inheritance, Method Overriding

- **Activities & Quizzes** — the class activities and looping challenges, each with the full VB.NET code answer
